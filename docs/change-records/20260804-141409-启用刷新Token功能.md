# 启用刷新 Token 功能

## 基本信息

- 修改时间：2026-08-04 14:14:09
- 修改人：郭梓鹏
- 关联需求/问题：为 Web Ant Design 应用启用刷新 Token
- 影响范围：`apps/web-antd/src/preferences.ts`

## 修改背景

为启用 Token 自动刷新机制，需要在应用级偏好配置中显式开启刷新 Token 能力。修改前应用未设置 `enableRefreshToken`，访问令牌过期后无法使用框架的刷新 Token 能力。

## 修改内容

在 `apps/web-antd/src/preferences.ts` 的 `app` 配置中新增 `enableRefreshToken: true`，并添加对应说明注释。

## 涉及文件

- `apps/web-antd/src/preferences.ts`
- `docs/change-records/README.md`
- `docs/change-records/20260804-141409-启用刷新Token功能.md`

## 兼容性与风险

启用后，访问令牌过期时将尝试使用刷新 Token 获取新令牌；需要后端接口支持对应的刷新 Token 流程。
