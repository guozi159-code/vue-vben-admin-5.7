# 精简默认界面与功能入口

## 基本信息

- 修改时间：2026-08-04 11:11:02
- 修改人：郭梓鹏
- 关联需求/问题：无
- 影响范围：Web Ant Design 应用的登录页工具栏与登录方式、主布局用户下拉菜单、全局主题/标签页/顶栏工具偏好，以及本地开发服务启动行为

## 修改背景

为精简项目默认内容，减少当前项目不需要的界面入口和操作选项。修改前无已知问题或限制。

## 修改内容

1. 登录页仅在工具栏保留语言切换，隐藏验证码登录、二维码登录、第三方登录和注册入口。
2. 清空主布局用户下拉菜单中的个人中心、项目文档、GitHub 和问题反馈入口，并清理相关无用依赖。
3. 默认使用浅色主题，隐藏偏好设置按钮和标签页“更多”入口。
4. 关闭全局搜索、刷新、侧边栏切换、主题切换和时区等默认工具，将其余工具位置调整至用户下拉区域。
5. 配置 Vite 开发服务启动后自动打开浏览器。
