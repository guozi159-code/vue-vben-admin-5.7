## 修改背景

为项目添加基础 Skill。修改前无已知问题或限制。

## 修改内容

### 添加基础 Skill

在 `.agents/skills` 中添加以下基础 Skill：

- `frontend-design`
- `skill-creator`

两个 Skill 均从 Anthropic 官方 `anthropics/skills` 仓库完整同步，保留对应的说明、脚本、资源和许可证文件。

### 增加外部 Skill 来源管理

新增 `.agents/external-skills.json`，按 Skill 分别声明 Git 仓库地址、分支和仓库内路径，支持后续从不同仓库引入其他外部 Skill。

新增 `.agents/external-skills.lock.json`，记录每个外部 Skill 实际同步的 Commit SHA 和内容哈希，用于版本追溯和一致性校验。项目自行沉淀且未登记在外部清单中的 Skill 不受同步机制影响。

### 增加同步和校验命令

新增 `scripts/sync-agent-skills.mjs`，提供以下命令：

```bash
pnpm skills:sync
pnpm skills:sync frontend-design
pnpm skills:check
```

同步脚本支持多仓库来源、同源仓库复用、`SKILL.md` 元数据校验、本地修改保护、临时目录替换和失败回滚。

### 调整 Git 忽略规则

移除 `.gitignore` 中对 `.agents` 的忽略规则，使项目级 Skill、来源清单和锁文件可以纳入版本控制并共享给项目成员。

## 兼容性与风险

- 本次修改不影响应用构建产物和运行时功能。
- `skill-creator` 与 Codex 内置 Skill 同名，可能同时出现在 Skill 选择器中。
- 同步外部 Skill 会引入上游最新内容，执行同步后应通过 Git diff 审阅变更再提交。
- 同步器检测到受管 Skill 存在本地修改时会停止覆盖；需要定制时应改为项目自有 Skill。

## 验证方式

1. 执行 `pnpm skills:sync`，确认两个基础 Skill 可以从上游完整同步并更新锁文件。
2. 执行 `pnpm skills:sync frontend-design`，确认可以单独同步指定 Skill。
3. 执行 `pnpm skills:check`，确认两个 Skill 的来源声明、锁文件和本地内容一致。
4. 执行 `node --check scripts/sync-agent-skills.mjs`，确认同步脚本语法正确。
5. 执行 `pnpm exec oxlint scripts/sync-agent-skills.mjs` 和格式检查，确认静态检查通过。
6. 对项目自有改动执行暂存区空白字符检查，结果通过；外部 `skill-creator` 上游文件保留两处原始尾随空格，以维持内容哈希一致。

## 回滚方式

使用 `git revert <本次提交的 Commit SHA>` 回滚本次提交；或删除新增的 `.agents` 内容和同步脚本，移除 `package.json` 中的 `skills:sync`、`skills:check` 命令，并恢复 `.gitignore` 对 `.agents` 的忽略规则。
