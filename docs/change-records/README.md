## 记录约定

- 每个相对独立的重要修改单独创建一个 Markdown 文件。
- 文件名格式：`YYYYMMDD-HHmmss-修改概要.md`。
- 修改概要应简短明确，建议控制在 10～20 个字以内。
- 新记录从 [`template.md`](./template.md) 复制并填写。
- 完成记录后，在下方索引中按时间倒序添加一行。
- 仅涉及格式调整或显而易见的小修复，可只保留 Git 提交记录。
